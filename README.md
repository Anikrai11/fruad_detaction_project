# Fraud Detection Project

This is a simple and easy-to-understand fraud detection project using Python and Machine Learning.

## 🚀 Features
- Detects fraudulent transactions
- Uses Machine Learning classification
- Easy to understand for beginners
- Clean Python code (easy_fruad_dataction.py)

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-Learn
- NumPy

## ▶️ How to Run
1. Clone the repository:
   git clone https://github.com/Anikrai11/fruad_detaction_project.git
2. Install dependencies:
   pip install pandas scikit-learn
3. Run the file:
   python easy_fruad_dataction.py
